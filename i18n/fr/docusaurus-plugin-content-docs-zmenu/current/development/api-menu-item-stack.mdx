# MenuItemStack

Apprenez à utiliser `MenuItemStack` pour créer des items dynamiques, compatibles avec les placeholders, dans zMenu.

## Aperçu {#apercu}

`MenuItemStack` est une abstraction de l'`ItemStack` de Bukkit qui fournit :
- Le support des placeholders dans les noms, lores et autres propriétés
- La construction dynamique d'items selon le contexte du joueur
- Une manipulation simple des propriétés de l'item
- Le support du custom model data, des enchantements, etc.

## Récupérer un MenuItemStack {#recuperer-un-menuitemstack}

### Depuis la configuration d'un bouton

Dans un bouton personnalisé, récupérez l'item configuré :

```java
public class MyButton extends Button {

    @Override
    public ItemStack getCustomItemStack(@NotNull Player player, boolean useCache, @NotNull Placeholders placeholders) {
        // Recuperer le MenuItemStack depuis la configuration YAML
        MenuItemStack menuItemStack = this.getItemStack();

        // Construire et retourner l'ItemStack
        return menuItemStack.build(player, useCache, placeholders);
    }
}
```

### Depuis l'InventoryManager

Charger un MenuItemStack depuis une configuration :

```java
InventoryManager manager = menuPlugin.getInventoryManager();

// `path` doit finir par un point : le loader lit "path.to.item.material", "path.to.item.name", ...
MenuItemStack itemStack = manager.loadItemStack(configuration, "path.to.item.", file);

// Depuis une map (par exemple la section `item:` d'une action) - utilise par item_give, item_edit, ...
MenuItemStack fromMap = manager.loadItemStack(file, "path.to.item", map);
```

`file` est le fichier YAML lu (utilisé pour les messages d'erreur). `MenuPlugin#loadItemStack(YamlConfiguration, String, File)` fait la même chose.

Pour convertir un `ItemStack` Bukkit existant en `MenuItemStack`, utilisez `InventoryManager#toMenuItemStack(ItemStack)` : la méthode retourne un `MenuItemStackConversion` avec le `menuItemStack` et la liste des `unsupportedComponents` qui n'ont pas pu être représentés (`isReadable()` vaut `true` quand rien n'est perdu).

## Construire des ItemStacks

### Construction simple

```java
MenuItemStack menuItemStack = getItemStack();

// Construction simple avec traitement des placeholders
ItemStack item = menuItemStack.build(player);
```

### Construction avec contrôle du cache {#construction-avec-controle-du-cache}

```java
// Sans cache (toujours a jour)
ItemStack item = menuItemStack.build(player, false);

// Avec cache (reutilise le resultat quand c'est possible)
ItemStack itemCached = menuItemStack.build(player, true);
```

### Construction avec des placeholders personnalisés {#construction-avec-des-placeholders-personnalises}

```java
import fr.maxlego08.menu.api.utils.Placeholders;

MenuItemStack menuItemStack = getItemStack();
Placeholders placeholders = new Placeholders();

// Enregistrer des placeholders personnalises
placeholders.register("price", "1000");
placeholders.register("currency", "coins");
placeholders.register("stock", "42");

// Construire avec les placeholders personnalises
ItemStack item = menuItemStack.build(player, false, placeholders);
```

## Placeholders personnalisés {#placeholders-personnalises}

### Créer des placeholders {#creer-des-placeholders}

```java
Placeholders placeholders = new Placeholders();

// Valeurs texte
placeholders.register("player_name", player.getName());
placeholders.register("server_name", "MySever");

// Valeurs numeriques (converties en texte)
placeholders.register("balance", String.valueOf(economy.getBalance(player)));
placeholders.register("level", String.valueOf(player.getLevel()));

// Etats booleens
placeholders.register("is_premium", player.hasPermission("premium") ? "Yes" : "No");

// Valeurs formatees
placeholders.register("health", String.format("%.1f", player.getHealth()));
```

## Exemple complet : item de boutique dynamique

### SellBuyButton.java

```java
package com.example.shop.buttons;

import fr.maxlego08.menu.api.MenuItemStack;
import fr.maxlego08.menu.api.button.Button;
import fr.maxlego08.menu.api.engine.InventoryEngine;
import fr.maxlego08.menu.api.utils.Placeholders;
import com.example.shop.ShopPlugin;
import com.example.shop.ShopItem;
import org.bukkit.entity.Player;
import org.bukkit.event.inventory.InventoryClickEvent;
import org.bukkit.inventory.ItemStack;
import org.bukkit.plugin.Plugin;

import java.math.BigDecimal;

public class SellBuyButton extends Button {

    private final ShopPlugin plugin;

    public SellBuyButton(Plugin plugin) {
        this.plugin = (ShopPlugin) plugin;
    }

    @Override
    public ItemStack getCustomItemStack(@NotNull Player player, boolean useCache, @NotNull Placeholders placeholders) {
        // Recuperer le MenuItemStack depuis la configuration
        MenuItemStack menuItemStack = this.getItemStack();

        // Recuperer les donnees du cache du joueur
        var cache = plugin.getCacheManager().getCache(player);
        ShopItem shopItem = cache.get("current_item");
        BigDecimal price = cache.get("price", BigDecimal.ZERO);

        // Creer les placeholders
        placeholders.register("price", plugin.getEconomyManager().format(price));
        placeholders.register("item_name", shopItem.getName());
        placeholders.register("quantity", String.valueOf(shopItem.getQuantity()));

        // Verifier si le joueur peut payer et ajouter le statut
        boolean canAfford = plugin.getEconomyManager().has(player, price);
        placeholders.register("status", canAfford ? "&aYou can afford this!" : "&cNot enough money!");

        // Construire et retourner
        return menuItemStack.build(player, false, placeholders);
    }

    @Override
    public void onClick(Player player, InventoryClickEvent event,
                       InventoryEngine inventory, int slot, Placeholders placeholders) {
        super.onClick(player, event, inventory, slot, placeholders);

        var cache = plugin.getCacheManager().getCache(player);
        ShopItem shopItem = cache.get("current_item");
        BigDecimal price = cache.get("price", BigDecimal.ZERO);

        if (plugin.getEconomyManager().withdraw(player, price)) {
            shopItem.give(player);
            player.sendMessage("§aPurchase successful!");
            player.closeInventory();
        } else {
            player.sendMessage("§cYou don't have enough money!");
        }
    }
}
```

## Exemple complet : bouton de tri avec états {#exemple-complet--bouton-de-tri-avec-etats}

### SortButton.java

```java
package com.example.sort.buttons;

import fr.maxlego08.menu.api.MenuItemStack;
import fr.maxlego08.menu.api.button.Button;
import fr.maxlego08.menu.api.engine.InventoryEngine;
import fr.maxlego08.menu.api.utils.Placeholders;
import com.example.sort.SortPlugin;
import com.example.sort.SortType;
import org.bukkit.entity.Player;
import org.bukkit.event.inventory.InventoryClickEvent;
import org.bukkit.inventory.ItemStack;
import org.bukkit.plugin.Plugin;

import java.util.List;

public class SortButton extends Button {

    private final SortPlugin plugin;
    private final String enableText;
    private final String disableText;
    private final MenuItemStack loadingItemStack;
    private final List<SortType> sortTypes;

    public SortButton(Plugin plugin, String enableText, String disableText,
                     MenuItemStack loadingItemStack, List<SortType> sortTypes) {
        this.plugin = (SortPlugin) plugin;
        this.enableText = enableText;
        this.disableText = disableText;
        this.loadingItemStack = loadingItemStack;
        this.sortTypes = sortTypes;
    }

    @Override
    public boolean isPermanent() {
        return true;
    }

    @Override
    public ItemStack getCustomItemStack(@NotNull Player player, boolean useCache, @NotNull Placeholders placeholders) {
        var cache = plugin.getCacheManager().getCache(player);
        SortType currentSort = cache.get("current_sort", SortType.DATE_DESC);

        MenuItemStack itemStack = this.getItemStack();

        // Enregistrer l'etat de chaque type de tri
        for (SortType sortType : sortTypes) {
            String state = (sortType == currentSort) ? enableText : disableText;
            String displayName = state.replace("%sorting%", sortType.getDisplayName());
            placeholders.register(sortType.name(), displayName);
        }

        return itemStack.build(player, false, placeholders);
    }

    @Override
    public void onClick(Player player, InventoryClickEvent event,
                       InventoryEngine inventory, int slot, Placeholders placeholders) {
        super.onClick(player, event, inventory, slot, placeholders);

        var cache = plugin.getCacheManager().getCache(player);
        SortType currentSort = cache.get("current_sort", SortType.DATE_DESC);

        // Afficher l'etat de chargement
        for (Integer buttonSlot : getSlots()) {
            inventory.getSpigotInventory().setItem(buttonSlot, loadingItemStack.build(player));
        }

        // Calculer le prochain type de tri
        int currentIndex = sortTypes.indexOf(currentSort);
        int direction = event.isRightClick() ? -1 : 1;
        int nextIndex = (currentIndex + direction + sortTypes.size()) % sortTypes.size();
        SortType nextSort = sortTypes.get(nextIndex);

        // Mettre a jour le cache et rafraichir
        cache.set("current_sort", nextSort);

        plugin.getScheduler().runAsync(task -> {
            // Trier en asynchrone
            plugin.getSortManager().sortItems(player, nextSort);

            // Mettre a jour l'inventaire sur le thread principal
            plugin.getScheduler().runNextTick(w -> {
                inventory.updateInventory();
            });
        });
    }
}
```

## Exemple complet : bouton interrupteur

### ToggleButton.java

```java
package com.example.settings.buttons;

import fr.maxlego08.menu.api.MenuItemStack;
import fr.maxlego08.menu.api.button.Button;
import fr.maxlego08.menu.api.engine.InventoryEngine;
import fr.maxlego08.menu.api.utils.Placeholders;
import org.bukkit.entity.Player;
import org.bukkit.event.inventory.InventoryClickEvent;
import org.bukkit.inventory.ItemStack;
import org.bukkit.plugin.Plugin;

public class ToggleButton extends Button {

    private final Plugin plugin;
    private final String settingKey;
    private final MenuItemStack enabledItem;
    private final MenuItemStack disabledItem;

    public ToggleButton(Plugin plugin, String settingKey,
                       MenuItemStack enabledItem, MenuItemStack disabledItem) {
        this.plugin = plugin;
        this.settingKey = settingKey;
        this.enabledItem = enabledItem;
        this.disabledItem = disabledItem;
    }

    @Override
    public ItemStack getCustomItemStack(@NotNull Player player, boolean useCache, @NotNull Placeholders placeholders) {
        boolean isEnabled = getSettingValue(player);

        // Utiliser un MenuItemStack different selon l'etat
        MenuItemStack itemStack = isEnabled ? enabledItem : disabledItem;

        placeholders.register("status", isEnabled ? "&aEnabled" : "&cDisabled");
        placeholders.register("action", isEnabled ? "disable" : "enable");

        return itemStack.build(player, false, placeholders);
    }

    @Override
    public void onClick(Player player, InventoryClickEvent event,
                       InventoryEngine inventory, int slot, Placeholders placeholders) {
        super.onClick(player, event, inventory, slot, placeholders);

        // Inverser le parametre
        boolean currentValue = getSettingValue(player);
        setSettingValue(player, !currentValue);

        // Rafraichir l'inventaire
        inventory.updateInventory();

        // Prevenir le joueur
        String newStatus = !currentValue ? "enabled" : "disabled";
        player.sendMessage("§aSetting " + settingKey + " " + newStatus + "!");
    }

    private boolean getSettingValue(Player player) {
        // L'implementation depend de votre systeme de stockage
        return plugin.getConfig().getBoolean("players." + player.getUniqueId() + "." + settingKey, false);
    }

    private void setSettingValue(Player player, boolean value) {
        plugin.getConfig().set("players." + player.getUniqueId() + "." + settingKey, value);
        plugin.saveConfig();
    }
}
```

## Charger un MenuItemStack depuis la configuration

### ButtonLoader personnalisé {#buttonloader-personnalise}

```java
package com.example.loader;

import fr.maxlego08.menu.api.MenuItemStack;
import fr.maxlego08.menu.api.InventoryManager;
import fr.maxlego08.menu.api.button.Button;
import fr.maxlego08.menu.api.button.DefaultButtonValue;
import fr.maxlego08.menu.api.loader.ButtonLoader;
import com.example.buttons.ToggleButton;
import org.bukkit.configuration.file.YamlConfiguration;
import org.bukkit.plugin.Plugin;

public class ToggleButtonLoader extends ButtonLoader {

    private final InventoryManager inventoryManager;

    public ToggleButtonLoader(Plugin plugin, InventoryManager inventoryManager) {
        super(plugin, "MY_TOGGLE");
        this.inventoryManager = inventoryManager;
    }

    @Override
    public Button load(YamlConfiguration config, String path, DefaultButtonValue defaultButtonValue) {
        // `path` finit deja par un point
        String settingKey = config.getString(path + "setting-key", "default");

        // Charger le MenuItemStack de l'etat active (notez le point final)
        MenuItemStack enabledItem = inventoryManager.loadItemStack(config, path + "enabled-item.", defaultButtonValue.getFile());

        // Charger le MenuItemStack de l'etat desactive
        MenuItemStack disabledItem = inventoryManager.loadItemStack(config, path + "disabled-item.", defaultButtonValue.getFile());

        return new ToggleButton(this.plugin, settingKey, enabledItem, disabledItem);
    }
}
```

## Propriétés de MenuItemStack {#proprietes-de-menuitemstack}

`MenuItemStack` est chargé depuis la même section `item:` utilisée partout dans zMenu : toutes les clés sont donc documentées dans la [référence des items](../configurations/items/item) et la [référence des composants](../configurations/items/components). Un court exemple :

```yaml
item:
  material: DIAMOND_SWORD
  name: "&6&lLegendary Sword"
  lore:
    - "&7A powerful weapon"
  amount: 1
  model-id: 12345
  enchantments:
    - SHARPNESS:5
  glow: true
  components:
    unbreakable: true
```

Les alias acceptés par le loader (`modelId`, `enchants`, `display-name`, ...) sont listés sur la page des items.

## Bonnes pratiques

1. **Utilisez les placeholders** - Profitez du système de placeholders pour le contenu dynamique
2. **Utilisez le cache** - Utilisez `build(player, true)` pour les items statiques
3. **Créez des placeholders réutilisables** - Faites une classe utilitaire pour les placeholders courants
4. **Gérez les valeurs nulles** - Fournissez toujours des valeurs par défaut
5. **Gardez des lores courts** - Les lores trop longs posent des problèmes d'affichage
6. **Testez avec PlaceholderAPI** - Vérifiez que les placeholders PAPI fonctionnent
