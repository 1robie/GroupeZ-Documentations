# zMenu+

**zMenu+** est l'addon premium pour zMenu qui ajoute de puissantes fonctionnalités avancées pour améliorer votre expérience de création d'inventaires.

## Qu'est-ce que zMenu+ ?

zMenu+ étend les capacités du plugin gratuit zMenu avec des fonctionnalités supplémentaires conçues pour les propriétaires de serveurs qui veulent encore plus de contrôle et de fonctionnalités dans leurs menus.

## Fonctionnalités {#fonctionnalites}

zMenu+ inclut des fonctionnalités exclusives qui ne sont pas disponibles dans la version gratuite :

### Types de boutons avancés {#types-de-boutons-avances}
Types de boutons supplémentaires pour des comportements de menu plus complexes, comme les boutons [`PAGINATION`](./configurations/buttons/types/pagination) et [`DYNAMIC_PAGINATION`](./configurations/buttons/types/dynamic-pagination), qui affichent une liste paginée dans un menu (les boutons de navigation `PAGINATION_NEXT` et `PAGINATION_PREVIOUS` font partie du plugin gratuit).

### Actions améliorées {#actions-ameliorees}
Types d'actions supplémentaires pour des menus plus interactifs.

### Support premium
Support prioritaire pour les clients zMenu+.

### Accès anticipé {#acces-anticipe}
Obtenez l'accès aux nouvelles fonctionnalités avant leur sortie dans la version gratuite.

## Achat

Vous pouvez acheter zMenu+ depuis :

**Minecraft Inventory Builder** : [https://minecraft-inventory-builder.com/resources/zmenu-addon](https://minecraft-inventory-builder.com/resources/zmenu-addon)

## Installation

1. Achetez et téléchargez zMenu+ depuis le lien ci-dessus
2. Assurez-vous que zMenu est déjà installé sur votre serveur
3. Placez le fichier JAR de zMenu+ dans votre dossier `plugins/`
4. Redémarrez votre serveur

:::info Nécessite zMenu
zMenu+ est un addon et nécessite le plugin de base zMenu pour fonctionner. Assurez-vous d'avoir installé zMenu en premier.
:::

## Questions fréquentes {#questions-frequentes}

### zMenu+ est-il requis pour utiliser zMenu ?

Non, zMenu est entièrement fonctionnel en tant que plugin gratuit. zMenu+ est optionnel et ajoute des fonctionnalités supplémentaires.

### Puis-je essayer zMenu+ avant d'acheter ?

Rejoignez le serveur Discord pour voir des exemples et poser des questions sur ce que zMenu+ offre.

### Y a-t-il une politique de remboursement ?

Veuillez consulter le site Minecraft Inventory Builder pour leur politique de remboursement.

### Mes inventaires fonctionneront-ils avec zMenu+ ?

Oui ! zMenu+ est entièrement compatible avec vos configurations zMenu existantes. Il ajoute seulement de nouvelles fonctionnalités - il ne change pas le fonctionnement des fonctionnalités existantes.
